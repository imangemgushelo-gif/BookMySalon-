
# BookMySalon - East London
Find. Book. Glow.

Salon Booking App for East London, Eastern Cape.

Features:
- Customers find salons near them in East London (Mdantsane, Southernwood, Quigney, Beacon Bay, Gonubie, Vincent, Amalinda)
- Customers book in 30 seconds
- Owners see Total Bookings Today / Week / Month
- Owners Accept / Decline / Reschedule bookings
- Live Directions with real GPS tracking
- Deposits via PayFast / Yoco

Built with GitHub + Cloudflare Pages.
Live: https://bookmysalon.pages.dev
